# Contributing

## Issues

Issues are welcome: bug reports, questions and feature requests. For a bug, please include the
cakedome and SeaORM versions, the database and a small example that shows the problem.

The project is maintained in spare time, so replies may take a while.

## Pull requests

Pull requests are not accepted and are closed automatically. Please open an issue instead; if you
have a fix in mind, describe it there.

## Security

Please do not report vulnerabilities in public issues. See [SECURITY.md](SECURITY.md).
